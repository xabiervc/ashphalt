# Ashphalt — Claude Code instructions

## Read first

Read `docs/GDD.md`, `docs/CANONICAL_PREPRODUCTION_INDEX.md`, `docs/PRODUCTION_SCOPE_FREEZE.md`, and `docs/LEVEL_A_PREPRODUCTION_SIGNOFF.md` before implementation.

## Authority

Product canon comes from `GDD.md`. Normative specialist documents define systems. Operational documents define the current prototype. Prompts are execution aids and cannot override design authority.

## Scope

Implement only the frozen prototype scope unless an approved scope-change record exists. Multiplayer, full campaign expansion, final production assets, and live-service features are deferred.

## Before changes

Provide plan, files, acceptance criteria, risks, and wait for confirmation. Never claim a quality gate passes without evidence.
