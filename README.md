# Ashphalt

Ashphalt is a narrative arcade street-racing game about velocity, risk, reputation, and the consequences a driver leaves across a living city.

## Preimplementation status

**Documented Level A: achieved.** The reviewer packet maps A1 identity, A2 gameplay, A3 narrative, A4 production, A5 accessibility, A6 traceability, and A7 honest closure.

Start here: [`docs/LEVEL_A_REVIEWER_PACKET.md`](docs/LEVEL_A_REVIEWER_PACKET.md).

This is not a claim that gameplay is already validated. The first implementation milestone is Track A vehicle control and its evidence package.
