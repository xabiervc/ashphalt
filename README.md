# Ashphalt: Aftermath

A single-player-first open-city arcade vehicular-combat racing game built around The Ash Race, Chaos Rating, The Fire Key, persistent city states, and consequence-driven driving.

## Current readiness

- Documented pre-production: complete.
- Level-A controlled-prototype readiness: approved by repository scope.
- Mandatory prototype scope: frozen.
- Unreal implementation: not started.
- Validation evidence: not started.

Start with `docs/GDD.md`, then `docs/CANONICAL_PREPRODUCTION_INDEX.md`, `docs/PRODUCTION_SCOPE_FREEZE.md`, `docs/VERTICAL_SLICE_OPERATIONAL_PLAN.md`, and `docs/LEVEL_A_PREPRODUCTION_SIGNOFF.md`.

Documentation is not evidence of fun, performance, accessibility, or awards. Those require builds, tests, playtests, and signed gates.
