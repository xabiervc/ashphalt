# Vehicle feel metrics

## Prototype benchmark

Use a repeatable test map with straight, slalom, 90-degree turn, hairpin, ramp, debris field, wet section, collision wall, and recovery lane.

## Measure

- 0-100 km/h acceleration.
- Top speed and speed variance.
- Braking distance from 50/100/150 km/h.
- Turning radius at three speeds.
- Time to recover from oversteer.
- Airborne landing stability.
- Damage-induced handling change.
- Weather grip delta.
- Camera readability at speed.
- Voluntary replay rate in blind tests.

## Initial target bands

| Metric | Target band |
|---|---|
| First playable top speed | 160-210 km/h |
| Main-route average speed | 75-125 km/h |
| Decision reaction window | 0.8-2.5 s |
| Standard obstacle visibility | 2.0+ s at approach speed |
| Moderate collision recovery | 1-4 s |
| Critical failure from normal collision | not before 3-5 major impacts |
| Player-initiated replay after tutorial | 60%+ in test group |

Tune by archetype after the base vehicle passes Q1.
