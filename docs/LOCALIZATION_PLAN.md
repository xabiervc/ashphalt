# Localization plan

## Languages

Source language: English. First localization target: Spanish. Additional languages are decided after the vertical slice.

## Requirements

Use localization keys from day one, context notes, plural/gender handling where needed, expansion testing, subtitle limits, UI resizing, voiced-line mapping, and fallback text.

## QA

Pseudo-localization, long-string tests, missing-key tests, font coverage, number/date/unit rules, subtitles, menus, radio interruptions, and save compatibility are required before content lock.
