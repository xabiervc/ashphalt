# Production readiness gate

Production begins only when:

- Vertical slice passes Q3 with external playtest evidence.
- Platform profile and performance budgets are approved.
- Asset pipeline has delivered representative approved assets.
- Core save migration, regression, load, accessibility, localization, and telemetry tests pass.
- Narrative, content, legal, rating, and sensitive-theme reviews have owners and approvals.
- All core systems have implementation owners and rollback/cut rules.
- The remaining content backlog is estimated and compatible with schedule/resources.
- No mandatory feature remains a vague aspiration.
