# The Ash Race campaign

The campaign is now structured as a season with seven stages: Starting Line, The Crown, The Works, The Verge, The Salt Run, The Lowlands, and The Gate. Each stage contains required and optional events, a rival beat, a city-state transition, a decision, and a departure route.

See `ASH_RACE_SEASON_STRUCTURE.md`, `CITY_STATE_MACHINE.md`, `CAMPAIGN_STAGE_SPECIFICATION.md`, and `CAMPAIGN_QA_MATRIX.md` for the production-level structure and acceptance tests.
