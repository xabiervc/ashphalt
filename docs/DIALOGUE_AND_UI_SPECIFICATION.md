# Dialogue and UI specification

## Dialogue requirements

Dialogue is short, reactive, and skippable. Every important line has speaker, context, faction, localization key, prerequisite, consequence, and fallback text.

## Core HUD

- Speed and gear.
- Current objective.
- Race timer.
- Score and combo.
- Heat level.
- Component damage.
- Vehicle condition.
- Credits/parts earned.
- Faction consequence notification.

## Menus

- Event board.
- Vehicle garage.
- Workshop repair.
- Tuning.
- Faction standing.
- Map/district access.
- Story decision review.
- Save/load and settings.

## Accessibility

Include subtitles, text size, color-safe indicators, remappable controls, steering sensitivity, camera shake toggle, reduced effects, non-contact pedestrian mode, difficulty options, and hold/toggle alternatives.
