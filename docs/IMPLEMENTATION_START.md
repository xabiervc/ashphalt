# Ashphalt — implementation start

## Current state

- Pre-production documentation: complete.
- Unreal project: not created yet.
- Playable implementation: not started.
- Current milestone: implementation handoff.

## First objective

Create a minimal Unreal Engine 5.7+ project and reach the first playable slice described in `docs/FIRST_PLAYABLE_SPEC.md`.

## Required order

1. Create the Unreal project using the agreed C++/Blueprint structure.
2. Verify the project opens, compiles, and packages a development build.
3. Add the test district with placeholder geometry.
4. Add one Chaos vehicle and basic controls.
5. Add collision damage and a workshop reset.
6. Add one race event and one rival placeholder.
7. Add one reputation event and one visible consequence.
8. Run the acceptance checklist and record results in `PROGRESS.md`.

## No premature scope

Do not implement multiplayer, final art, a full campaign, procedural city generation, online services, live-service systems, or a large vehicle roster before the first playable slice is accepted.

## Required evidence

Every milestone must provide a commit, a test map, a short test report, profiling observations, known issues, and an explicit pass/fail result.
