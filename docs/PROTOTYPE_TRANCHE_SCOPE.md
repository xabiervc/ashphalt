# Prototype tranche scope

## Tranche A — vehicle control

### Included

- One vehicle model or representative proxy.
- One metric test map.
- Camera and input baseline.
- Acceleration, braking, steering, grip/drift hypothesis, collision response, recovery, and reset.
- Basic telemetry and debug commands.
- Reproducible test scenarios.
- Blind control playtest protocol.

### Excluded until promotion

- Open-world breadth.
- Full campaign.
- Multiple districts.
- Complete police/traffic ecosystem.
- Full economy and seasonal content.
- Final art, audio, VFX, localization, and narrative presentation.

### Promotion evidence

- Build ID and commit.
- Metric capture.
- Blind-playtest results.
- Critical bug and regression report.
- Accessibility smoke test for controls and camera.
- Decision log entry: promote, revise, or cut.

## Guardrail

A prototype feature is not promoted because it exists. It is promoted because it produces evidence against a defined hypothesis.
