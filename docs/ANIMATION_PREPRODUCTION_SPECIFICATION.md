# Animation pre-production specification

## Vehicle animation

Wheel/suspension response, steering, body roll, impact deformation, detached parts, smoke states, repair reattachment, doors/panels, and destruction transitions.

## NPC animation

Walk, run, panic, flee, stumble/recover, inspect damage, repair, celebrate, protest, signal, enter/exit vehicle, and emergency response.

## Rival presentation

Named rivals require readable driving signatures: aggressive ramming, precise lines, evasive movement, showboat stunts, or protective convoy positioning.

## Technical requirements

Define skeleton, control rig, retargeting, animation budget, LOD behavior, network deferral, interrupt rules, and failure fallback for every authored animation group.
