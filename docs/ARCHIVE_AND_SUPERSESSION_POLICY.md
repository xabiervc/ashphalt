# Archive and supersession policy

## Current authority

Only documents linked from `PRODUCT_SOURCE_OF_TRUTH.md`, the current GDD, and the current roadmap can define implementation scope.

## Superseded material

Earlier broad summaries remain useful as history but are not authoritative if a specialist document provides a more precise rule. Do not create new files named `FINAL`, `PREMIUM`, `COMPLETE`, or `100_PERCENT` to imply authority.

## Required metadata

Specialist documents should state scope, owner, revision date, dependencies, status, and superseded references when they are next edited.

## Repository navigation

README and `CLAUDE.md` must point contributors to the source of truth and the locked vertical slice first.
