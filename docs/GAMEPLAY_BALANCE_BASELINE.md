# Gameplay balance baseline

## Prototype targets

- First event duration: 4-7 minutes.
- Workshop interaction: 3-8 seconds in-world presentation.
- Early vehicle survives 3-5 major impacts before critical degradation.
- Authority escalation from first incident to elite response: 90-180 seconds depending on player behavior.
- A normal event should provide enough credits for partial repair plus progress toward one upgrade.
- A failed event should not create an unrecoverable economy state.

## Validation matrix

Test conservative, aggressive, stunt-focused, destruction-focused, and unlucky players. Record completion time, damage, credits, reputation, heat, repairs, and retry count.

## Tuning principle

Numbers are hypotheses. Any value that is not validated by controlled tests must be labelled prototype-only in data and documentation.
