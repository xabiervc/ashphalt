# Progression decision design

## Core principle

Upgrades must change decisions, not simply increase every number.

## Examples

- More armor: survive Authority rams, but slower acceleration and more repair cost.
- Better tires: stronger dry route control, weaker performance in ash or rain.
- Salvage rig: more parts from exploration, less speed.
- Signal spoofer: slower heat growth, fewer Authority-aligned workshop benefits.
- Ram attachment: better destruction, reduced front visibility and steering response.

## Progression loop

Event choice → risk/reward decision → earned resources/reputation → meaningful vehicle or route option → new strategy.

## Validation

A playtester should be able to explain why they installed an upgrade and name a route or event where it changed their decision.
