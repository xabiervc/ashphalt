# Vertical slice readiness gate

The project is ready to build the vertical slice only when:

- First five minutes and first-hour learning are implemented as testable scenarios.
- Track A control prototype passes Q1.
- The Crown open district has a stable blockout and streaming plan.
- One complete race, free-roam activity, rival, Authority escalation, weather change, workshop, decision, city-state consequence, and aftermath are specified.
- Audio/VFX/animation/UI placeholders exist with budgets.
- Accessibility baseline is implemented and persistence-tested.
- Save/load, error recovery, and debug commands exist.
- Performance benchmark runs on target hardware.
- No unresolved design contradiction blocks implementation.
