# A6 — Traceability assessment

## Chain

`vision → pillar → system → content → interface → data → test → acceptance criterion`

## Closed decisions

The canonical index and traceability materials identify the source document, owner, implementation surface, validation method, and acceptance evidence for each major pillar and system.

## Review rule

If a requirement cannot be traced to a test or acceptance criterion, it remains open and must be registered as a gap rather than silently considered complete.
