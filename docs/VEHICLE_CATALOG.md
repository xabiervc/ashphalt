## Component baselines

Each vehicle defines chassis, engine, wheel, body, and attachment health separately. Initial design range: chassis 700-1,500, engine 300-900, wheel 100-300 per wheel, body 250-900.

## Balance note

These figures are starting data for prototype comparison. They must be validated through controlled laps, ramming tests, weather tests, and player playtests before being treated as production values.
