# Level-A production validation plan

## Objective

Promote Ashphalt from Level A documented pre-production to Level A validated for full production only through evidence.

## Phase 1 — Freeze

Freeze product canon, mandatory prototype scope, core metrics, target profile, and acceptance tests. New ideas become backlog proposals, not silent scope.

## Phase 2 — Track A: control

Build the vehicle-control prototype and metric test map. Measure input response, acceleration, braking, turning, recovery, camera readability, collision response, damage, and voluntary replay. Pass Q1 only with blind-playtest evidence and no critical physics instability.

## Phase 3 — Track B: challenge

Add the open Crown blockout, route fork, landmark navigation, rival, Authority response, weather route change, objective HUD, and failure recovery. Pass Q2 only when players understand route, objective, threat, damage, and failure cause without coaching.

## Phase 4 — Track C: progression

Add workshop and three upgrades with real trade-offs. Pass only when players choose different builds for different objectives and can explain why.

## Phase 5 — Crown vertical slice

Deliver the locked operational slice at representative quality. Test streaming, sound, VFX, accessibility, save/load, city state, narrative comprehension, and performance.

## Phase 6 — Repeatability

Implement a second small event using the same pipeline. Verify that content can be produced without inventing new architecture or breaking budgets.

## Promotion decision

Promote only if Q1-Q3, accessibility, performance, save/replay, narrative, and repeatability evidence meet thresholds. Otherwise revise and retest.
