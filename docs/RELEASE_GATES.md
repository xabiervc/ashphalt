# Release gates

## Prototype gate

Vehicle movement and collisions are controllable, stable, and fun for a short test session.

## First playable gate

One complete event can be played from preparation to aftermath, including damage, repair, reward, reputation, and one consequence.

## Vertical slice gate

The intended quality bar is visible in one district with representative vehicles, AI, weather, UI, audio placeholders, save/load, and narrative choice.

## Alpha gate

Core systems are feature-complete, content pipelines are stable, performance risks are measured, and no major design system remains undefined.

## Beta gate

Content and localization inputs are complete, regression suite passes, save migration works, accessibility and platform requirements are tested, and critical defects have owners.

## Release gate

No release-blocking defects, legal review completed, platform certification passed, crash reporting active, support documentation ready, and rollback/hotfix process tested.
