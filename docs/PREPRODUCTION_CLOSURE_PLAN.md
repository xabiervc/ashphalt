# Pre-production closure plan

## Documentation closure

1. Resolve all production decisions in `PRODUCTION_DECISION_REGISTER.md`.
2. Validate every coverage-matrix row has vision, catalog, data, pipeline, metrics, QA, and accessibility entries.
3. Generate the first Unreal project and replace assumptions with project-specific identifiers.
4. Create Track A control prototype.
5. Run first quality gate with blind playtesters.
6. Update each matrix row with evidence links.

## Definition of 100% pre-production

All planned domains are documented, all external decisions have owners and deadlines, and no mandatory system remains implicit. This does not mean the game is implemented or balanced.

## Definition of production readiness

The first playable passes Q1/Q2, technical budgets are measured, asset pipelines work, and the vertical-slice scope is locked.
