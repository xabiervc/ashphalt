# Decision ownership and deadlines

## Open decisions

| Decision | Owner | Required by | Default if unresolved |
|---|---|---|---|
| Exact Unreal version | technical owner | project creation | latest approved 5.7+ stable version |
| Primary PC hardware profile | technical owner | Track A benchmark | recommended desktop profile documented at setup |
| First input scheme | design/UX | Track A | keyboard/mouse + XInput controller |
| Final title clearance | legal owner | public announcement | working title only |
| Pedestrian presentation/rating | design/creative | Track B | stylized non-contact option |
| Music/voice budget | production owner | vertical slice | placeholder/original temp assets |
| Target localization languages | production owner | content lock | English source + Spanish first target |
| Binary asset storage | technical owner | project creation | Git LFS or approved equivalent |

## Rule

Unresolved production decisions cannot silently become permanent design. Record the chosen value, rationale, affected documents, evidence, and rollback cost.
