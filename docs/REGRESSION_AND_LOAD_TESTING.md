# Regression and load testing

## Regression

Every fixed defect receives a reproduction scenario and automated/manual regression test. Run core, save, event, AI, streaming, audio, accessibility, localization, and replay suites on every milestone build.

## Load tests

- Maximum traffic density.
- Maximum Authority escalation.
- Maximum simultaneous destruction/VFX.
- Weather transition during cell streaming.
- Save/load at event boundary.
- Long free-roam session.
- Repeated city-state transitions.
- Large replay playback.

## Results

Store build ID, hardware, seed, scenario, duration, peak metrics, failures, and owner. A load test without recorded conditions is not evidence.
