# Quality evidence register

## Evidence states

- `DOCUMENTED`: requirement exists and has an owner/test definition.
- `IMPLEMENTED`: build contains the feature.
- `VALIDATED`: tests/playtests meet criteria.
- `APPROVED`: gate owner accepts evidence.

## Current state

All pre-production rows are `DOCUMENTED`. No core gameplay row is `IMPLEMENTED`, `VALIDATED`, or `APPROVED`.

## Required evidence record

Build ID, commit, hardware/profile, test scenario, seed, participant profile, raw result, interpretation, defect IDs, decision, owner, and date.
