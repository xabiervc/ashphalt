# Event catalog

## Campaign role

Events are stages of The Ash Race and contribute to the player's Chaos Rating, city state, reputation, and access to The Gate.

## Required event data

Every event defines participants, route, primary/secondary objectives, city-state contribution, Chaos Rating rules, timer, weather seed, heat policy, reward budget, reputation effects, unlocks, failure state, aftermath, and replay ID.
