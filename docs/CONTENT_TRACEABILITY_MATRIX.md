# Content traceability matrix

| Content type | Prototype | Crown slice | Full target | Required evidence |
|---|---:|---:|---:|---|
| Open subdistricts | 1 blockout | 1 polished section | 25 | traversal and density tests |
| Player vehicles | 1 placeholder | 1 tuned vehicle | 12-20 | handling/damage tests |
| Rivals | 1 | 1 authored rival | 10-20 appearances | behavior/relationship tests |
| Main events | 1 | 1 | 5 | event and aftermath tests |
| Secondary events | 0-1 | 2-3 | 20-30 | objective/reward tests |
| Free-roam activities | 1 | 1-2 | 20-30 | discovery/outcome tests |
| Characters | placeholders | 3-5 active | 15-25 | arc/state tests |
| Weather states | forced | 1 route-changing | 6-10 | physics/readability tests |
| Authority units | 1 | 1 interceptor | 6-10 | escalation/recovery tests |
| Upgrades | 3 | 3 | 20-30 | trade-off tests |
| Music cues | placeholders | Crown layers | full campaign | mix/state tests |
| VFX families | placeholders | damage/weather/pursuit | full catalog | readability/performance tests |

## Rule

A target number is not a commitment to fill content blindly. Every item must have purpose, owner, data, acceptance criteria, and a cut decision.
