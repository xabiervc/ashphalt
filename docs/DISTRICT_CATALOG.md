# District catalog

The primary campaign geography is five open cities with approximately five subdistricts each: The Crown, The Works, The Verge, The Salt Run, and The Lowlands. The detailed subdistrict catalog is in `SUBDISTRICT_CATALOG.md`.

Each subdistrict requires a landmark, main route, alternate route, workshop or safe point, event, free-roam activity, faction presence, emergency space, and recovery path for lost players.
