# Privacy and telemetry

## Principle

Telemetry is optional, minimal, transparent, and useful. The single-player game must function fully without telemetry.

## Default data

Collect no personal content. If opted in, collect pseudonymous build/session ID, crash/ensure metadata, performance aggregates, feature completion, and anonymized error context. Do not collect raw voice, free text, precise location, contacts, or unrelated device data.

## Controls

Explain purpose, retention, categories, opt-in state, deletion/export route where required, and regional legal basis. Do not gate core progression on consent.

## Testing

Verify disabled telemetry creates no network request and that logs do not contain personal or secret data.
