# Open-world vertical slice

## Locked slice

The first vertical slice is an explorable section of The Crown, not a standalone race track.

## Required content

- One open subdistrict with continuous driving.
- One major landmark and two secondary landmarks.
- One main circuit race inside the city.
- One discoverable shortcut outside the official route.
- One free-roam activity.
- One workshop and three upgrades.
- One rival that can be encountered outside the race.
- One Authority pursuit.
- One weather state that changes a route.
- One faction decision.
- One persistent city-state transition.
- One consequence visible after returning to the district.
- Ten-minute free-roam session without mandatory loading.
- HUD, accessibility baseline, save/load, and replay scenario.

## Exit gate

The slice must pass Q1 vehicle feel, Q2 first playable, and Q3 vertical-slice gates. It must demonstrate that exploration adds meaningful choices rather than empty driving time.
