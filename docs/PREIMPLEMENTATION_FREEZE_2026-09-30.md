# Ashphalt — preimplementation freeze

## Freeze date

2026-09-30.

## Classification

**Documented Level A preimplementation baseline: frozen.**

This freeze means the project can begin controlled implementation without reopening identity, core loop, narrative frame, accessibility requirements, principal technical risks, or acceptance strategy.

It does not claim that the game is fun, validated, optimized, emotionally effective, or approved for full production.

## Normative entry point

`CANONICAL_PREPRODUCTION_INDEX.md` is the reviewer and implementation entry point. Domain-specific canonical documents named there are normative. Drafts, prompts, historical documents, and superseded material are informative only.

## First implementation tranche

Track A vehicle control and metric test map only. Track B, Track C, open-world breadth, full campaign, and presentation expansion remain outside the first tranche until evidence justifies promotion.

## Change rule

Identity, scope, system contracts, and acceptance criteria are frozen. Runtime hypotheses may change through the decision log after evidence. Structural changes require explicit impact analysis and traceability updates.

## Exit condition

The freeze ends only when the prototype gate is reviewed with a build ID, metrics, playtest evidence, known risks, and a recorded decision.
