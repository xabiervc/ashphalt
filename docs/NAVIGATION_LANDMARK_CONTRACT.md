# Navigation landmark contract

## Landmark data

Every landmark defines ID, zone, transform, silhouette, material/value palette, discovery radius, route relationships, audio cue, map representation, and accessibility description.

## Crown landmarks

- Crown Needle: visible city-scale orientation anchor.
- Blue Line Station: entrance to Old Transit shortcut.
- Authority Arch: checkpoint and pursuit trigger landmark.
- Floodgate Nine: route/weather state indicator.
- Row 13 Garage: workshop and recovery anchor.

## Acceptance

A new player can identify the workshop, main route, shortcut entrance, and Authority zone without a permanent objective line. Optional guidance remains available.
