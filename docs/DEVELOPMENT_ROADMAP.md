# Development roadmap

## Milestone 0 — Documentation complete

Exit: all mandatory pre-production documents exist, link, and have no hidden blockers.

## Milestone 1 — Technical vehicle prototype

Exit: one vehicle drives, brakes, turns, collides, resets, and remains stable on the test track.

## Milestone 2 — First playable

Exit: one event, rival, damage, workshop, reward, reputation change, and consequence work end to end.

## Milestone 3 — Vertical slice

Exit: one polished district, 3-5 vehicles, several event types, traffic, basic Authority, weather, UI, save/load, and one narrative decision.

## Milestone 4 — Alpha

Exit: all core systems integrated, content pipeline stable, performance risks measured, major progression loop playable from start to end.

## Milestone 5 — Beta

Exit: content complete, balance pass, accessibility, localization readiness, save migration, regression suite, and release candidate process.

## Major risks

Vehicle feel, Chaos stability, traffic performance, AI deadlocks, content volume, scope growth, deterministic replay divergence, and legal review of title/assets.
