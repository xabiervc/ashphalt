# Production repeatability test

## Purpose

Prove that the project is not dependent on one-off heroics or undocumented knowledge.

## Test

Create a second event in a different Crown zone using the same data contracts, asset metadata, test harness, UI conventions, and QA process as the first event.

## Pass criteria

- No new core architecture required.
- No undocumented design decision blocks work.
- New content passes validation and profiling.
- Regression suite remains green.
- Effort and defects are recorded.
- A second designer/developer can follow the process from the repository.
