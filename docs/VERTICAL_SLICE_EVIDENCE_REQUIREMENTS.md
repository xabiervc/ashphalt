# Vertical slice evidence requirements

## Required package

- Build ID and commit.
- Hardware/profile.
- Content inventory.
- Walkthrough video or structured session log.
- Performance capture.
- Save/load report.
- Replay/determinism report where applicable.
- Accessibility option and user-test report.
- Narrative comprehension report.
- Bug/regression report.
- Playtest participant summary.
- Known risks and proposed decisions.

## Acceptance

The Crown slice must be playable by someone who did not author it. The reviewer must be able to complete the core loop, understand the consequence, recover from a failure, and identify at least one reason to replay.
