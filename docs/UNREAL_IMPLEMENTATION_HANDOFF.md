# Unreal implementation handoff

## First playable slice

One district, one player vehicle, one rival, one closed-loop event, one workshop, component damage, one repair, one shortcut, one faction reputation change, and one visible consequence.

## Order

1. Project and modules.
2. Test district.
3. Vehicle movement and camera.
4. Collision/damage.
5. Race event state.
6. Rival placeholder.
7. Workshop repair.
8. Reputation event.
9. One consequence.
10. HUD and debug tools.

## Required output per phase

Code/assets changed, test scenario, acceptance results, profiling result, known issues, documentation updates, and a commit recommendation.

## Stop conditions

Stop and report if a design conflict, missing asset, engine limitation, unstable physics result, or unbounded scope is discovered. Do not silently work around a product decision.
