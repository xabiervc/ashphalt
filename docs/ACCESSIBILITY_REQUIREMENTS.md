# Accessibility requirements

## Visual

- Body text minimum target: 24 px equivalent at 1080p in default UI; scalable to at least 150%.
- Critical HUD text and objective text must remain readable at 200% UI scale without clipping.
- Contrast target: WCAG AA-equivalent for UI text where applicable; critical information uses redundant icons/shapes.
- Color modes: deuteranopia, protanopia, tritanopia, monochrome/high contrast.
- Subtitles: size, background opacity, speaker name, sound-effect captions, position, and safe-area controls.

## Input

- Full keyboard, mouse, and controller remapping.
- Analog sensitivity/dead-zone controls.
- Hold/toggle alternatives.
- No mandatory rapid button presses.
- Optional assisted steering, braking, route guidance, and recovery.

## Time and difficulty

- Adjustable game speed in single-player, with UI/audio adaptation.
- Separate difficulty components: driving assistance, rival aggression, Authority intensity, damage severity, weather severity, navigation assistance, and economy recovery.
- Frequent autosave at workshop, event start, event completion, decision, and stage transition.
- Reasonable retries and fail-forward outcomes.

## Audio/cognitive

- Independent volume controls, mono mode, visual equivalents for critical audio, reduced alarm intensity, pause, objective reminders, and simplified HUD option.

## User testing

Test with keyboard users, controller users, low-vision users, color-vision-diverse users, deaf/hard-of-hearing users, motor-impaired users, and cognitive-load-sensitive users where feasible. Record task completion, confusion, fatigue, and option effectiveness.
