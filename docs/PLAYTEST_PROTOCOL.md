# Playtest protocol

## Sessions

- Blind 10-minute control test.
- 20-30 minute first-playable session.
- 45-60 minute Crown slice.
- Accessibility-focused sessions.
- Return session after at least 48 hours.

## Record

Participant profile, build/seed, completion, route, collisions, damage, score, heat, upgrades, confusion, failure cause, consequence recall, replay intention, accessibility issues, and direct quotes.

## Ethics

Obtain consent, minimize personal data, allow withdrawal, avoid collecting unnecessary recordings, and anonymize reports.
