# Platform matrix

## Initial target

| Platform | Scope | Target |
|---|---|---|
| Windows PC | primary | development and first release target |
| Steam Deck-class handheld | evaluation | performance/accessibility compatibility target |
| PlayStation/Xbox | deferred | evaluate after vertical slice |
| Nintendo Switch-class hardware | deferred | not assumed due to open-city/physics budget |

## PC baseline to define at project creation

Record CPU, GPU, RAM, VRAM, storage, OS version, controller devices, resolution, and target frame rate. Maintain minimum and recommended profiles.

## Certification

Console certification is not part of the current implementation scope but must be considered before platform commitment. Platform-specific save, input, suspend/resume, achievement, crash, and accessibility behavior requires a later gate.
