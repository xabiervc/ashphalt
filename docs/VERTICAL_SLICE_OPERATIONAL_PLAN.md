# Vertical slice operational plan

## Slice identity

The Crown open subdistrict, played as a complete 20-30 minute first session and a 45-60 minute repeat session.

## Exact sequence

1. Workshop Row: inspect damaged Vandal Rook, perform repair, choose one of three upgrades.
2. Financial Ruins: drive to Crown Needle, learn route landmarking.
3. Event A — Crown Circuit: finish first or disable one rival; official route plus Old Transit shortcut.
4. Event B — The Stray Signal: investigate distress signal and choose repair, tow, raid, or ignore.
5. Event C — Authority Pressure: trigger or evade an interceptor response after destruction.
6. Weather event: Floodgate Nine changes access to Flooded Underground.
7. Faction decision: protect settlement infrastructure or maximize Chaos Rating.
8. Aftermath: city state changes; Workshop Row, route access, rival dialogue, and UI update.

## Required metrics

Session duration, first input response, route choice, collisions, damage, repair use, score/heat, activity discovery, decision time, consequence recall, frame/physics/AI/streaming time, save/load success, accessibility option persistence.

## Success criteria

- No blocker crash or data loss.
- Player completes or meaningfully fails the loop without developer intervention.
- Player can explain objective, route choice, damage cause, upgrade trade-off, and consequence.
- Performance and streaming remain within the current target profile.
- Q1 and Q2 evidence is captured; Q3 is not claimed until presentation is polished.
