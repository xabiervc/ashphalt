# First playable slice

The first playable is now split into three evidence-driven tracks: control, challenge, and progression. Track A must pass before Track B, and Track B before Track C.

The final first playable includes an open Crown subdistrict, one vehicle, one rival, Authority response, damage, workshop, one upgrade choice, one race, one shortcut, one free-roam activity, one faction consequence, and a city-state update. It is not approved until the measurable acceptance tests and blind-playtest criteria pass.
